1. 核心结论

一句话：音源决定起点，传输决定上限，设备决定你实际听到多少。三者要匹配，任何一环短板都会让高规格白花钱。
优先级结论说明
🔴 P0128kbps 与 320kbps 在普通设备上差距可闻；320kbps 与 CD 无损在百元耳机上几乎无感先把钱花在设备上，再买高规格音源
🔴 P0"无损"只保证文件不丢数据，不保证传到耳朵时不 lossy蓝牙会重新压缩；iPhone + AirPods 最高 AAC 约 256kbps
🔴 P0HiRes / DSD 需要前端 + 好耳机 + 安静环境三件套手机直推 + 百元耳机听 HiRes，和听 FLAC 没区别
🟡 P1音箱先定场景：听歌 2.0，看电影回音壁 + 实体低音炮单箱体蓝牙音箱变不出物理立体声
🟢 P2小尾巴（便携解码耳放）是性价比最高的"音质升级件"500-1000 元档就能让手机上的有线耳机明显变好

2. 音质五级阶梯

① 有损低码率
MP3/AAC 128-192kbps
约 3-5MB / 首
删掉泛音与残响。安静环境细听，吉他尾音发干、镲片边缘毛躁、声场变窄。适合：背景音、流量受限、老旧车机。
② 有损高码率
MP3 320kbps / AAC 256kbps
约 8-12MB / 首
有损里的高配，320kbps 能保留约 19-20kHz 高频。通勤路上已够用；盲听测试中大多数人分不出它与 CD 无损的差别。
③ CD 级无损
FLAC / ALAC / WAV
16bit / 44.1kHz，约 1411kbps
约 30-80MB / 首
分水岭。不删一个采样点，完整保留波形。百元以上耳机或音箱上，与 MP3 的差距明显可闻：高频细节与声场还原更好。多数人的"无损会员"买到这里就够了。
④ HiRes 高解析
24bit / 96-192kHz FLAC
约 2000-6000kbps
约 100-300MB / 首
位深从 16 提到 24（动态 96dB → 144dB），高频延伸更从容。对多数随身设备，24bit/96kHz 已是能听出差别的一档。注意：部分平台"母带"是升频而非原生母带。
⑤ DSD 母带
DSD64/128/256
2.8-11.2MHz，1bit 脉冲密度
约 200-500MB / 首
换了一套编码逻辑，高频过渡更顺滑、空间感自然。流媒体几乎不提供，需本地文件 + 支持 DoP/DSD Native 的专业 DAC。门槛最高、受众最小。
存储参考：100 首 320kbps MP3 约 1GB；100 首 FLAC 约 5-8GB；100 首 HiRes 约 15-30GB。64GB 手机全下 HiRes 很快撑满。

11. 术语速查

术语含义
码率 kbps每秒音频数据量，粗略反映压缩程度；高码率不等于好听
位深 / 采样率16bit/44.1kHz 是 CD 标准；24bit/96kHz 以上算 HiRes
FLAC / ALAC两种主流无损压缩格式，FLAC 通用，ALAC 是苹果生态
M4A容器格式，里面可能是有损 AAC，也可能是无损 ALAC，别看扩展名判断音质
ANC主动降噪，用反向声波抵消低频稳态噪音，对人声基本无效
LDAC / LHDC高码率蓝牙编码，需手机和耳机双方支持，否则自动降级
SRC 重采样安卓系统把高规格音频强制降采样，绕过方法是 USB 独占输出
小尾巴便携解码耳放，插手机 Type-C，提升推力和底噪控制
RMS / 峰值功率RMS 是额定持续功率，选音箱认准 RMS，峰值数字没有参考意义
后倒相孔音箱低频反射结构，靠墙摆放会形成驻波让低频轰头发闷
