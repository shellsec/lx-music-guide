如何导入

  1. 打开「设置 → 自定义源」。
  2. 在线导入单源，或在支持订阅的增强版中添加清单。
  3. 启用导入的音源，查看初始化结果。

支持自动切换的增强版可按本地顺序重试。全部失败时会检查订阅更新，更新失败时保留原音源。

Docker 部署

适用于安装了 Docker Engine 和 Compose 插件的 Linux（amd64 / arm64）。

查看安装命令

直连 GitHub

curl -fsSL https://raw.githubusercontent.com/shellsec/boleserver/main/deploy/install.sh -o /tmp/boleserver-install.sh && sudo bash /tmp/boleserver-install.sh

第三方代理加速，默认安装到 /opt/boleserver

curl -fsSL https://gh-proxy.com/https://raw.githubusercontent.com/shellsec/boleserver/d2762bcfbc773a0baf81cbca5df1ba1bde2d7a29/deploy/install.sh -o /tmp/boleserver-install.sh && sudo env BOLE_IMAGE=gh-proxy.com/docker/ghcr.io/shellsec/boleserver:latest bash /tmp/boleserver-install.sh

已用 root 登录时去掉 sudo。代理镜像设置保存在安装目录的 .env。

首次使用

  1. 打开 http://服务器IP:9527/admin/，设置 8–128 位管理员密码。已有部署继续使用原密码。
  2. 在「播放器 → 设置 → 系统 → 管理员登录 → 管理 / 添加」填写音源订阅地址，也可上传音源脚本。
  3. 在同一局域网用 iPhone、iPad 或鸿蒙 NEXT 的浏览器打开服务地址。
