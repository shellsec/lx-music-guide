按平台筛选，展开卡片查看安装方式。

音源与订阅

安装客户端后，可按需要添加可信的自定义源。

导入订阅清单

  1. 准备你有权使用的 HTTPS 订阅清单地址。一个 JSON 清单可包含多个音源，每项包含 id、name 和 url。
  2. 在支持订阅的客户端中打开「设置 → 自定义源」，选择「添加订阅清单」。
  3. 粘贴你准备的地址，保存清单，按需启用导入的音源并查看初始化结果。

地址格式示例（仅示意）

https://example.com/sources.json

导入单个音源

  1. 打开「设置 → 自定义源」。
  2. 选择「导入单个源」，按客户端提示粘贴脚本地址或选择本地文件。
  3. 启用导入的音源，查看初始化结果。

请仅导入可信来源的脚本，并在获得相应授权的范围内使用音乐内容。

用 BoleServer 自建播放

在家里的电脑或 NAS 运行服务，用浏览器听歌。

项目仓库 ↗

桌面端

支持 Windows、macOS 和 Linux。桌面端集成管理界面与 Web 播放器。

GitHub 发行页 ↗

Docker 部署

适用于安装了 Docker Engine 和 Compose 插件的 Linux（amd64 / arm64）。

查看安装命令

直连 GitHub

curl -fsSL https://raw.githubusercontent.com/shellsec/boleserver/main/deploy/install.sh -o /tmp/boleserver-install.sh && sudo bash /tmp/boleserver-install.sh

已用 root 登录时去掉 sudo。

首次使用

  1. 打开 http://服务器IP:9527/admin/，设置 8–128 位管理员密码。已有部署继续使用原密码。
  2. 在「播放器 → 设置 → 系统 → 管理员登录 → 管理 / 添加」填写音源订阅地址，也可上传音源脚本。
  3. 在同一局域网用 iPhone、iPad 或鸿蒙 NEXT 的浏览器打开服务地址。

其他播放方式

车载与智能音箱

车机可用手机蓝牙或在支持的设备上通过 CarPlay 播放。小爱同学 Pro 可连接手机蓝牙。车载专版已停止规划，可穿戴设备暂无独立入口。

飞牛 NAS 与在线听歌

已有飞牛 NAS 和官方音乐应用，可查看 fnOS 音乐增强扩展。临时听歌也可直接打开汽水音乐网页。
